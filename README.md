# 心动档案 · The Love Journal

五项恋爱情感趣味测试，纯 HTML、CSS、JavaScript 实现，无需后端或外部服务。

包含恋爱人格、吸引倾向、相处习惯、情侣偏好比较和理想恋爱剧本。
作答仅存储在用户当前浏览器，不上传答案；不要求登录或个人信息。

趣味测试，仅供自我探索，不代表专业心理评估。

## GitHub Pages

将此目录内的全部文件放入仓库 main 分支根目录。
在 Settings → Pages → Build and deployment 中选择 Deploy from a branch，
分支选 main，目录选 / (root)，保存并等待 Pages 构建完成。
入口为 index.html，.nojekyll 用于跳过 Jekyll 处理。

所有资源均为相对路径，支持 GitHub Pages 的仓库子路径。
本地可直接双击 index.html 打开。线上首次使用不会自动继承本地文件版的浏览器记录。

参考：https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
